# 교육안내 · 수료증 · 거래명세서 (edu-invite)

영유아교육디자인연구소 — **링크 하나**로 교육 전 그룹챗방 입장 안내부터
교육 후 수료증 · 거래명세서까지 한 번에 드리는 앱.

`edu-docs`(수료증·거래명세서 앱)를 **복사해서 새로 만든 앱**이다. 원본은 그대로 살아 있다.

## 화면

- `/admin` (비밀번호 `1234`) — 원장님이 쓰는 곳.
  1. 교육 이름
  2. **무엇을 담을까요** — ① 교육안내(그룹챗) ② 수료증 ③ 거래명세서 (하나만도, 모두도 가능)
  3. 고른 것만 차례로 채우기
     - 교육안내: 교육명 · 안내글 · 그룹챗방 주소 · 입장 단추 글자
     - 수료증: 디자인 8종 고르기 + 과정명 · 교육기간 (여러 장 가능)
     - 거래명세서: 품목명 · 기본 금액
  4. 전달 링크 만들기 (짧은 주소 `/g/6자리`)
- `/g/<번호>` — 받는 분 화면.
  - 교육안내를 담았을 때: **신청자가 맞습니까? → 네! → 그룹챗방 입장 →
    "교육 이후 수료증·거래명세서 안내입니다. 이동하시겠습니까?" → 네 / 아니요**
  - 서류만 담았을 때: 예전 edu-docs와 똑같이 소개 → 서류 고르기 → PDF 받기
- `/?d=...` — 보관함이 안 될 때 쓰는 예비용 긴 링크(내용이 주소 안에 들어 있다).

## 고칠 곳

- 받는 분 화면 흐름 — `app/components/Docs.js` (`steps` 목록)
- 관리자 단계 — `app/admin/page.js` (`buildSteps`)
- 링크에 담는 내용의 모양 — `app/lib/share.js` (`emptyConfig`)
- 공급자(연구소) 정보 — `app/lib/supplier.js`
- 사업자등록증 그림 — `public/business_license.jpg` / 직인 — `public/seal.png`
- 수료증 디자인 위치값 — `app/lib/certDesigns.js` (A4를 595 x 841로 봤을 때의 px)

## 만든 방식

Next.js 14 (App Router, JavaScript). 문서 PDF는 html2canvas + jsPDF로 화면을 그대로 찍는다.
짧은 링크는 Vercel Blob 보관함(`BLOB_READ_WRITE_TOKEN`)에 내용을 저장하고 6자리 번호만 주소에 담는다.
